### 为什么推荐？
在当前前端开发中，以 shadcn/ui 为代表的无头组件已成为事实标准，并催生出众多优秀的生态分支（如 BoardUI 图表库、ShadcnStore 商业区块、Refero 设计规范及各种微动效库）。

然而，很多开发者在搭建设计系统或选型时面临两大困境：
1. **生态过度碎片化**：各个库散落在不同的独立站点，缺乏一个统一的对比视角；
2. **文档与实装脱节**：不少聚合站仅有静态截图或统计虚标，无法直观体验代码和可交互效果。

**`shadcn-hub`** 采用 Next.js 16 + Tailwind CSS v4 + @base-ui/react 构建，一站式将：
1. **shadcn/ui 官方全量 61 款核心组件**；
2. **BoardUI 19 款高阶仪表盘图表 + AI Agentic 智能体交互套件**；
3. **ShadcnStore 39 类商业营销/电商区块**；
4. **Refero 9 大主流设计风格实景**（Linear、Vercel Geist、Apple、Neo-Brutalism、Stripe、Supabase、Raycast、Notion、Perplexity）；
5. **HeroUI、beUI、RareUI、Transitions、BeautifulUI 微交互动效**；

全部集成并以“双层全局导航 + 全局 Cmd+K 搜索”的形式进行 **100% 严谨实机可交互渲染**。代码完全开源，且做到了零虚标对齐，希望能帮助到正在做前端架构、SaaS 或独立开发的朋友们。
